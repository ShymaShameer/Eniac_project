# Eniac_project
## Project Overview

This project analyzes internal e-commerce data from Eniac, a technology-focused online retailer, to evaluate the business impact of product discounting. 

This project involved a comprehensive Data Cleaning and Exploratory Data Analysis (EDA) pipeline. The goal was to transform raw, unreliable CSV files into a high-integrity dataset to answer critical business questions regarding revenue trends and discount strategies.

Using Python-based data analysis, this project transforms messy, non-anonymized raw data into a clean, reliable dataset and extracts insights on pricing, discounts, and seasonal sales patterns.

## The Data Challenge

The initial dataset contained several inconsistencies that could have led to incorrect business decisions. 
The key issues addressed included Missing values, Data integrity, Duplicate entries & Price discrepancies.

## Key Analysis Areas
* Product categorization for structured reporting and comparison
* Price distribution across different product categories
* Volume and frequency of discounted products
* Discount magnitude as a percentage of original prices
* Impact of seasonality and key events (e.g., Christmas, Black Friday) on sales
* Identification of data quality issues and recommendations for improvement

## Tools 
* Python (Pandas, NumPy) for data cleaning and transformation.
* Matplotlib / Seaborn for data visualization.
* Google collab Notebook for exploratory analysis and documentation.
